# VALORANT 5v5 Tactical FPS Web Edition

발로란트(VALORANT)의 전투 시스템, 맵, 요원 능력, 총기 메커니즘을 3D 웹 환경에서 완벽하게 구현한 브라우저 FPS 게임입니다.

## ⚡ 주요 핵심 기능 (Features)

### 1. 발로란트 제트 (Jett) 1:1 고유 시스템
- **칼날 폭풍 (Blade Storm, X)**: 1인칭 5개 부유 비수 에메랄드 네온 발광 및 유기적 웨이브 애니메이션
  - **좌클릭 (단일 투척)**: 이동/점프/활강 중 100% 무확산 핀포인트 정밀 투척 (헤드샷 150 즉사 / 몸통 50)
  - **킬 리셋 (Kill Reset)**: 적 처치 시 비수 5개 즉시 100% 완충 & "Watch this!" 보이스 피드백
  - **우클릭 (산탄 일제 사격)**: 전방 부채꼴 원뿔형 일제 투척 후 궁극기 종료
  - **공중 활강 (Passive Drift)**: 공중에서 스페이스바 유지 시 하강 속도 `-1.6 m/s` 제한 활강
- **상승기류 (Updraft, Q)**: 수직 급상승 고공 점프
- **순풍 (Tailwind, E)**: 이동 방향 순간 고속 돌진
- **연막구 (Cloudburst, C)**: 전방 12초 지속 구름 연막 전개

### 2. 7인 공식 요원 스킬 시스템
- **화령 (Phoenix)**: 불꽃 장막(벽), 화염탄, 잔불(연막), 업화(궁극기)
- **서린 (Sage)**: 서리 덫(55% 둔화), 빙벽(HP 400 물리 충돌체), 한기 구역, 빙결
- **무영 (Omen)**: 그림자 화살(정찰), 잔영(무적 대시), 감각 차단(실명), 그림자 사냥
- **강철 (Raze/Breach)**: 충격 수류탄, 전선 방패, 돌진, 파쇄
- **연화 (Skye)**: 회복의 씨앗(힐링 링), 뿌리 결박, 안개꽃, 재생
- **노은 (Killjoy)**: 전자 교란(침묵), 감시 드론, 과부하 지뢰, 정전
- **백호 / 제트 (Jett)**: 연막구, 상승기류, 순풍, 칼날 폭풍

### 3. 무끼임 원통-AABB 물리 엔진 (Anti-Stuck Physics)
- Cylinder-AABB 최단점 투영 및 3-Pass Relaxation 다중 완화
- 법선 성분만 감쇄하는 접선 속도 보존(`vel -= (vel · n) * n`)으로 90도 코너와 모서리에서도 부드러운 벽 타기(Wall Slide) 지원

### 4. 어센트 (ASCENT) 1:1 정밀 맵 및 16개 한글 전술 콜아웃
- B 사이트, A 사이트, 미드 안뜰, 캣워크, B 시장, A 트리, B 보바
- A/B 듀얼 전동 셔터문 ([F]키 조작 & 총격 파괴 가능)
- 16개 공식 전술 콜아웃 레이더 미니맵

### 5. 초소형 구획화 설정창 (Settings Modal)
- 일반, 조준선, 그래픽, 사운드, 조작 5개 탭 구획화
- 실시간 수치 배지 및 1행 원클릭 프리셋

## 🎮 조작법 (Controls)

| 키 | 동작 |
| :--- | :--- |
| **W, A, S, D** | 이동 |
| **Space** | 점프 / 제트 공중 활강 (길게 누르기) |
| **Shift** | 걷기 (정숙 보행) |
| **Ctrl** | 앉기 |
| **마우스 좌클릭** | 사격 / 비수 핀포인트 단일 투척 |
| **마우스 우클릭** | 조준(ADS) / 비수 일제 산탄 투척 |
| **R** | 재장전 |
| **1 / 2 / 3** | 주무기 / 보조무기 / 근접무기 |
| **C / Q / E / X** | 요원 고유 스킬 및 궁극기 |
| **B** | 상점 (구매 메뉴) |
| **Esc / P** | 설정창 열기 |
| **Tab** | 점수판 (5v5 전황판) |

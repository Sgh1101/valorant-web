# VALORANT // 5V5 CUSTOM PROTOCOL (TACTICAL ESPORTS SUITE)

Three.js 기반 100% 무설치, 브라우저에서 즉시 실행 가능한 발로란트 5v5 전술 FPS 웹 게임입니다.

---

## 🎮 실행 방법
1. `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 웨일 등 최신 웹 브라우저에서 바로 엽니다.
2. **커스텀 게임 로비(Custom Game Lobby)**:
   - 공격팀(5슬롯) vs 수비팀(5슬롯) 중 원하는 번호의 슬롯을 클릭하여 팀/자리를 선택합니다.
   - 빈자리는 **전술 AI 봇**이 자동으로 채워 5v5 대전을 진행합니다.
   - 맵(어센트, 바인드, 헤이븐, 사격장)을 선택하고 **[게임 시작 (START MATCH)]**을 클릭합니다.

---

## 🌐 멀티플레이 & AI 대체 (Drop-in Multi-Client)
- **무서버 브라우저 멀티 세션 동기화 (`BroadcastChannel`)**:
  - 새 브라우저 창/탭을 하나 더 띄우면 같은 로비에 즉시 접속됩니다!
  - 새 창에서 슬롯을 선택하면 해당 자리의 **AI 봇이 실시간으로 사람 플레이어로 교체(대체)**되어 대전할 수 있습니다.
  - `[ENTER]` 키로 팀 채팅을 주고받을 수 있습니다.

---

## 👻 사망 시 아군 AI 요원 빙의 시스템 (Bot Takeover)
- 교전 중 사망했을 때 화면 하단에 **`[SPACE] 아군 AI 요원 몸으로 빙의`** 알림이 나타납니다.
- `[SPACE]` 키를 누르면 살아있는 아군 봇 중 한 명의 시점/몸으로 즉시 전환되어, 해당 라운드가 끝날 때까지 클러치(역전) 플레이를 계속할 수 있습니다!

## 🗺️ 전장 4종 & 고유 기믹 (4 Maps & Signatures)
1. **어센트 (ASCENT)**:
   - 미드 광장과 캣워크, 마켓, A/B 사이트 및 헤븐 2층 발코니와 라디어나이트 엄폐 상자 배치.
2. **바인드 (BIND) - [작동하는 텔레포터 탑재]**:
   - 모로코 사막풍 A/B 사이트와 **양방향 순간이동기(Teleporter)** 기믹!
   - 텔레포터 입구(A Short / B Long)로 걸어 들어가면 포탈 사운드 및 섬광과 함께 반대편 출구로 즉시 워프!
3. **헤이븐 (HAVEN) - [3개 폭탄 사이트]**:
   - 동양식 파고다 사원 테마의 넓은 전장으로, **A 사이트, B 사이트, C 사이트** 3개 구역 어디든 스파이크 설치 가능!
4. **사격장 (THE RANGE) - [거리별 사격 & 표적봇 리스폰]**:
   - 바닥에 **10m, 20m, 30m, 50m 거리 표시선과 네온 라벨** 배치.
   - 각 거리마다 서 있는 표적 봇을 사격하여 명중/헤드샷을 연습할 수 있으며, 처치 시 즉시 재배치 리스폰!

## ⚡ 3D 실체형 요원 스킬셋 (Abilities)
- **[C] 연막구 (Cloudburst)**: 전방에 4.2m 크기의 거대한 3D 반투명 연막 구체를 전개하여 12초간 시야를 완벽 차단
- **[Q] 상승기류 (Updraft)**: 발밑에 원형 충격파 링을 발생시키며 17.5m 높이로 수직 도약
- **[E] 순풍 대시 (Tailwind)**: 이동 방향으로 순간 가속 대시하며 화면에 스피드라인 연출
- **[X] 칼날 폭풍 (Blade Storm)**:
  - 5자루의 빛나는 발광 쿠나이(비수)를 공중에 전개
  - **좌클릭**: 비수 1자루 정밀 투척 (몸통 50, 헤드 150 즉사)
  - **우클릭**: 남은 비수 전체를 전방에 일제 산탄 투척
  - **적 처치 시**: "Watch this!" 사운드와 함께 **5자루의 비수가 즉시 100% 재충전!**
